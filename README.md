# 💼 Shilpi's Portfolio

A responsive personal portfolio website that showcases my skills, projects
and contact details. Built from scratch using HTML, CSS and JavaScript.

🔗 **Live Site:** [Shilpi's Portfolio](https://shilpi-portfolio21.netlify.app/)

## ✨ Features
- Clean, responsive layout for mobile, tablet and desktop
- Automatic dark mode based on device settings
- Mobile menu and highlighted navigation for the section you are viewing
- Project section with live site and source code links
- One-click "Copy email" button and downloadable resume

## 🛠️ Tech Stack
- HTML5
- CSS3 (Flexbox, Grid, CSS variables)
- JavaScript (ES6+, DOM manipulation, Intersection Observer, Clipboard API)
